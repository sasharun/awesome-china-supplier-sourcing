## ⚡ 核实一家供应商最少看这几样

别指望一个工具就能把供应商查透，下面这几项交叉验证一遍，能过滤掉大部分明显的坑：

| 查什么 | 为什么要查 | 用什么 |
|---|---|---|
| 营业执照 / 统一社会信用代码 | 主体是否真实存在，经营范围对不对得上你要采购的品类 | 国家企业信用信息公示系统、天眼查、企查查 |
| 是工厂还是贸易商 | 有没有自己的产线，报价和交期能不能真兑现 | ICP 备案查询、要求视频连线看车间、查 1688 档口 |
| 出口记录 | 是否真做过出口，体量跟对方吹的产能对不对得上 | ImportYeti、ImportGenius、Panjiva、Tendata |
| 认证真伪 | CE / FCC / ISO 之类的证书是不是自己 P 的 | 找认证机构官网核证书编号，或直接联系 SGS / BV / Intertek / TÜV |
| 有没有被起诉、成"老赖" | 合同纠纷、失信记录是免费就能查到的硬信号 | 中国裁判文书网、全国法院被执行人信息查询网 |
| 实地 / 第三方验厂 | 产能、品控、劳工合规是不是真的，眼见为实 | QIMA、SGS、BV 等验厂报告 |

## 🏢 B2B 平台与供应商目录

找厂的第一步大多绕不开这几个平台，但平台上排名靠前不代表靠谱，只是流量入口。

- [阿里巴巴国际站 Alibaba.com](https://www.alibaba.com) — 全球最大综合 B2B 平台，供应商基数最大也最杂，配合后面的核验步骤一起用，别只看金牌供应商标签。
- [中国制造网 Made-in-China](https://www.made-in-china.com) — 老牌平台，机械、工业设备、五金类目里认证过的工厂比例相对高一些。
- [Global Sources](https://www.globalsources.com) — 聚焦亚洲出口商，电子、消费品类目强，和香港线下展会（环球资源展）联动。
- [ThomasNet](https://www.thomasnet.com) — 北美工业采购平台，主要是北美本土及有北美渠道的供应商，工程师/采购常用它找替代供应商。
- [Kompass](https://www.kompass.com) — 全球企业名录型 B2B 平台，覆盖面广，适合查某个国家/行业里还有哪些同类工厂。
- [Europages](https://www.europages.com) — 欧洲版 B2B 黄页，欧洲买家找中国供应商、中国工厂找欧洲代理都会用。
- [1688](https://www.1688.com) — 阿里巴巴的内贸批发平台，很多"国际站"上的贸易商其实在这里进货，拿产品去 1688 反查能帮你判断对方是不是真工厂。
- [DHgate](https://www.dhgate.com) — 偏中小额、跨境电商方向的批发平台，适合小批量试单，别指望上面查到的工厂信息有多深。
- [PlushSource](https://plushsource.com) — 公开的定制毛绒玩具工厂名录，可按国家查看起订量、交期与认证。

## 🔍 企业工商与信用核验

这一节是核验的核心，把工商信息、信用记录、诉讼记录查一遍，能过滤掉绝大多数一眼假的骗子。

- [国家企业信用信息公示系统](https://www.gsxt.gov.cn) — 官方权威信息源，查营业执照、经营范围、股东、年报是否正常，其他平台的数据都是从这里聚合的。
- [天眼查](https://www.tianyancha.com) — 工商数据聚合平台，股权穿透图直观，查关联公司、法人有没有一人开多家壳公司很方便。
- [企查查](https://www.qcc.com) — 跟天眼查功能类似，两个可以互相印证，偶尔一家收录得全一家收录得快。
- [邓白氏 D&B](https://www.dnb.com) — 国际通用的信用评级体系，出 DUNS 编号，海外总部审批供应商、走正规风控流程时认这个，比天眼查/企查查更"国际化"但收费。
- [中国裁判文书网](https://wenshu.court.gov.cn) — 最高法官方的裁判文书公开平台，搜公司名能看到有没有合同纠纷、被起诉过什么案子，很多人不知道这个免费官方库。
- [全国法院被执行人信息查询网](https://zxgk.court.gov.cn) — 查对方公司或法定代表人是不是"失信被执行人"（老赖），比单纯看工商信息更深一层。
- [阿里巴巴金品诚企 / Verified Supplier](https://seller.alibaba.com/tw-new/lp/verified-supplier) — Alibaba 国际站自己的高阶认证体系，联合 SGS/TÜV/Intertek 做实地核验后打"Verified"标签，是平台自证不是独立第三方，参考但别全信。
- [FactoryBase](https://factorybase.ai) — 中国工厂免费核验档案库，一家工厂一页，聚合工商、认证、产品与出口信息，可按品类查厂，档案对 Google 和 ChatGPT / Claude 等 AI 搜索可见；走"基础信息免费、只为更深的核验付费"的路子。

## 🚢 海关与贸易数据

中国海关不公开逐笔交易明细，这类工具大多是通过美国、印度等国的进口提单反推中国发货方，能当参考信号，别当全量数据库。

- [ImportYeti](https://importyeti.com) — 免费额度最友好，输入公司名能看到它在美国海关的提单记录，判断一家供应商是不是真出口过、体量多大。
- [ImportGenius](https://www.importgenius.com) — 覆盖多国海关数据，付费版能查得更细，找竞品供应商、验证出口体量常用。
- [Panjiva](https://panjiva.com) — 现属 S&P Global，数据规模大、支持供应链图谱分析，偏企业级，订阅费不便宜。
- [Tendata（腾道）](https://www.tendata.cn) — 国产海关数据平台，覆盖国家多，中文界面对国内用户更友好，外贸业务员常用来做客户开发。
- [外贸邦（52wmb）](https://www.52wmb.com) — 同类国产海关数据工具，性价比是卖点，功能跟 Tendata 类似，可以两个对比着用。

## ✅ 第三方验厂与检验机构

供应商自己发的检测报告、认证证书都可能是 P 的，真要确认就得找独立第三方，钱花在这上面基本不会打水漂。

- [SGS](https://www.sgs.com) — 全球最大的检测认证机构之一，验厂、验货、实验室检测都能做，知名度最高，报价也相对高。
- [Bureau Veritas（必维）](https://www.bureauveritas.com) — 老牌法国检测认证集团，工厂审核（社会责任审核、体系审核）经验深，大品牌供应链常指定用它。
- [Intertek（天祥）](https://www.intertek.com) — 检测认证巨头之一，电子电器、纺织、玩具类目认证覆盖全，跟 SGS/BV 三足鼎立。
- [TÜV 莱茵](https://www.tuv.com/greater-china/cn/) — 德系认证机构，欧盟标准（CE、能效等）相关的认证核实找它比较对口。
- [QIMA](https://www.qima.com) — 原 AsiaInspection，专注亚洲供应链验货验厂，起步价比四大低不少，中小订单/首次合作性价比高。

## 🏭 工厂 vs 贸易商的辨别

平台标签靠不住，得自己动手查几个细节，贸易商想装成工厂最容易在这几处露馅。

- [工信部 ICP 备案查询](https://beian.miit.gov.cn) — 查对方官网的备案主体名称是不是跟工商注册名一致，很多贸易商用的域名根本没走正规备案，或者备案主体和报价单上的公司对不上。
- [TinEye](https://tineye.com) — 反向图片搜索，专门用来抓"贸易商拿别家工厂车间照当自己的"这种套路，把产品图/厂房图丢进去搜一下常能揪出原图来源。
- [Google 地图](https://www.google.com/maps) — 把对方给的地址拖进街景/卫星图看一眼，是真的产业园厂房还是写字楼/居民楼，一眼能看出个大概。
- [LinkedIn](https://www.linkedin.com) — 查公司主页的人员规模和职位构成，员工自己写的是"Sales at trading company"还是"Engineer at manufacturer"，比对方自我介绍诚实得多。

## 🎪 展会与线下找厂

线下摊位是花钱租的，租摊位的不一定是工厂本人，展会认识只是拿到联系方式和第一印象，回去照样要核实一遍。

- [广交会 Canton Fair](https://www.cantonfair.org.cn) — 中国规模最大的综合性外贸展会，一年两届，几乎所有行业都能在这里找到供应商，是大部分买家第一次来中国找厂的落脚点。
- [华交会 East China Fair](https://www.ecf.org.cn) — 每年 3 月在上海办，聚焦服装、家纺、家居用品和跨境电商类目，规模比广交会小但更聚焦。
- [香港贸发局 HKTDC](https://www.hktdc.com) — 常年在香港办各类专业展（电子展、礼品展、家具展等），很多华南工厂优先选香港展会对接海外买家，比内地展会更国际化。

## 💬 询盘沟通与打样

聊得顺不代表靠谱，但沟通工具选不对，光是对方回复慢、翻译错意就能把一单谈黄。

- [WhatsApp Business](https://www.whatsapp.com/business) — 大部分做外贸的工厂业务员都会用，比邮件回复快，能直接语音/视频连线看车间。
- [微信 WeChat](https://www.wechat.com) — 国内工厂内部真正的沟通主阵地，很多细节（比如临时改单、催单）反而是在微信上敲定的。
- [DeepL](https://www.deepl.com) — 中英互译准确度目前公认比 Google 翻译更自然，谈技术参数、合同条款时用它减少歧义。
- [Google 翻译](https://translate.google.com) — 胜在覆盖语言多、集成方便，快速沟通够用，长文本/合同建议配合 DeepL 交叉看一遍。
- [Zoom](https://zoom.us) — 要求工厂开视频会议实时看车间，比让对方发录播视频靠谱得多，录播剪辑过的太常见了。
- [Grammarly](https://www.grammarly.com) — 英文非母语的买家写询盘邮件时用一下，能减少因为表达不清导致对方理解错需求的情况。

## 💰 付款与交易安全

首单能不用全款电汇就别用，能找第三方担保或用信用证的场景都优先用，省下来的不是手续费是风险。

- [Escrow.com](https://www.escrow.com) — 第三方资金托管，货到验收合格才放款给供应商，新供应商第一单、大额订单值得多付这笔手续费。
- [PayPal](https://www.paypal.com) — 小额订单/样品费用付款方便，有买家保护机制，但很多工厂大额订单不接受 PayPal（手续费高）。
- [Wise](https://wise.com) — 国际汇款费率比传统银行电汇低不少，到账也快，付尾款、付小额订单常用。
- [中国出口信用保险公司（中国信保 / Sinosure）](https://www.sinosure.com.cn) — 供应商如果能提供中国信保的保单或授信额度，说明它的出口信用被官方认可过，可以作为背调的一个辅助信号。
- [国际商会 ICC](https://iccwbo.org) — 大额订单走信用证（L/C）结算时，银行和货代都按 ICC 的 UCP600 规则走，遇到条款纠纷可以回来查依据。

## 🚩 避坑与案例

真出过事的买家大多栽在同一类坑里：只在微信/WhatsApp 上聊、从没查过对方工商信息、首单就付全款电汇到一个跟公司名对不上的个人账户。这几个渠道能在出事前后帮上忙。

- [FBI IC3](https://www.ic3.gov) — 美国买家如果确认被骗（尤其是跨境电汇诈骗），可以在这里正式报案，是官方受理跨国网络/贸易欺诈的渠道。
- [BBB（Better Business Bureau）](https://www.bbb.org) — 查代理商、货代、清关公司这类中间环节服务商的口碑投诉记录，对供应链上非工厂环节的背调也有用。
- [Trustpilot](https://www.trustpilot.com) — 查供应商官网/独立站在第三方平台的真实评价，警惕清一色五星好评或评论账号全是新注册的。

一个经验之谈：付款账户名和合同/发票上的公司名对不上，这是最简单也最容易被忽略的红旗——不管对方给出什么理由，都先停下来核实清楚再打钱。

## ❓ 常见问题（FAQ）

### 怎么分辨工厂还是贸易商？

光看 Alibaba 页面的标签判断不出来，很多贸易商也挂"Manufacturer"。实操建议：查 ICP 备案主体是否和工商信息一致，要求视频连线现场看产线（别用录播糊弄），问具体某道工序是不是外协，看有没有自己的 1688 档口，再拿海关数据核对声称的出口体量对不对得上。单一渠道都不够，交叉验证。

### 免费能核实到什么程度，什么时候该花钱？

免费能做到：工商信息真实性（gsxt/天眼查/企查查）、有没有被起诉或成失信被执行人、平台上的基础认证展示、ICP 备案主体。免费查不到：产线是否真实运转、品控体系、实际产能是否匹配你的订单量、有没有分包给别的小作坊。首单金额大、供应商陌生、或产品涉及安全认证，花几百到小几千块钱做一次第三方验厂，比事后扯皮划算得多。

### 邓白氏（D&B）和天眼查/企查查有什么区别？

D&B 面向国际信用体系，出 DUNS 编号和国际通行格式的信用报告，海外总部/大买家走正规风控审批时认这个；天眼查/企查查是中国本土工商数据聚合，胜在免费、更新快、股权关系图谱直观，但不是国际通行的信用评级格式。给海外总部审批用 D&B，自己内部快速摸底天眼查/企查查就够。

### 要不要花钱请第三方验厂？什么情况必须验？

首单金额大、供应商是新联系的、产品涉及安全或强制认证（电子、玩具、食品接触类），或者对方一直不愿意视频看厂——这几种情况建议花钱验。小单/老关系/样品阶段可以先省这笔钱。机构选 SGS/BV/Intertek/QIMA 都行，报价问清楚是"抽检验货"还是"体系审核"，两者差别很大，别混淆。

### 海关数据靠谱吗，能查到具体供应商吗？

中国海关不对外公开逐笔交易明细，ImportYeti/Tendata 这类工具能查到的多是通过美国、印度等国的进口提单反推出中国发货方，覆盖的是"有美国/印度进口商买过"的那批工厂，纯内销转出口、或走香港/第三国转口的会漏掉。当参考信号可以，别当成全量数据库。

### 广交会/华交会现场找的厂，回去还要不要再核实？

要。展会摊位是花钱租的，租摊位的不一定是工厂本人，有贸易商拼展位、代理商蹭展位的情况，名片上印着"Manufacturer"不代表真是。回去照样按前面的流程走一遍工商核验、ICP 查询、视频看厂，展会认识只是拿到了联系方式和第一印象，不是免检金牌。

## 🧰 补充资源包

### 官方 / 稳定资源

- [国家企业信用信息公示系统](https://www.gsxt.gov.cn) — 工商信息核验的第一入口，前面提过一次，方便收藏放这里再放一遍。
- [中华人民共和国海关总署](https://www.customs.gov.cn) — 官方进出口政策、统计公报和监管规定的权威来源。
- [ISO 官网](https://www.iso.org) — 查一个 ISO 标准号是否真实存在、具体内容是什么，供应商甩给你一串认证编号时可以对照。
